# Stack Technique

## Frontend
- **Next.js 14** (App Router) — framework React full-stack
- **Tailwind CSS** — styling utilitaire
- **shadcn/ui** — composants UI professionnels

## Backend
- **Next.js API Routes** — endpoints REST intégrés
- **Prisma ORM** — accès base de données typé
- **PostgreSQL** — base de données relationnelle

## Intelligence Artificielle
- **Claude API** (Anthropic) — génération principale
- **OpenAI GPT** — fallback / alternative

## Authentification
- **NextAuth.js** — gestion sessions et login

## Export
- **jsPDF** — export PDF
- **docx** — export Word

## Déploiement (prévu)
- Vercel (frontend + API) ou VPS
- Supabase (PostgreSQL managé)
